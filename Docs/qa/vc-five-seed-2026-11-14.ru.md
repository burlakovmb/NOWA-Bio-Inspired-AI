## Смысл и наблюдаемость метрик

Чтение Senior исходников `procurement_fitness.py:351–414` устанавливает, что обе метрики Stage 1b используют принятые заказы; ожидания и отклонённые заказы исключаются. `decision_consistency` группирует по `product_id`, вычисляет для каждого повторно заказанного товара наибольшую долю поставщика и усредняет эти доли без весов по объёму заказов товара. При менее четырёх принятых заказах или отсутствии повторного товара возвращает `0.5`. Это концентрация поставщика внутри каждого товара за квартал; реализации группировки по ситуации или времени нет, несмотря на более широкую формулировку docstring.

Диверсификация использует заказы товаров с минимум двумя достижимыми поставщиками на конец квартала: `0.6×(1−largest_supplier_share)+0.4×min(1,supplier_count/3)`. При менее двух принятых заказах значение `0.5`; при отсутствии товаров с альтернативами — `1.0`. Верность поставщику внутри товара и распределение между поставщиками совместимы, когда у разных товаров разные предпочтительные поставщики. Из одних формул не следуют ни несовместимость порогов, ни дефект агента/ядра.

Исправление после финального ревью доказательств, `2026-11-14`: сохранённые снимки сущностей включают поле `offers`. Во всех `250` собственных кварталах этой матрицы оно пустое: использованы прежние случайно генерируемые миры. Вместе с сохранёнными количествами принятых заказов по поставщикам этого достаточно для точного восстановления `supplier_diversification` во всех `250` кварталах. Прежняя ветвь `cost_efficiency` также восстанавливается из этих количеств и сохранённых `base_price_multiplier`; все `250` значений совпали в пределах `7.771561172376096e-16`. Эту дополнительную проверку только JSON выполнил координатор после независимого ревью; это не новый обучающий прогон и не расширение вердикта ревью.

Связи товара и поставщика для каждого заказа по-прежнему отсутствуют, поэтому `decision_consistency` нельзя восстановить из решений. Последний квартальный журнал решений trainer не сериализуется. Прежнее утверждение об отсутствии сети предложений и невозможности восстановления обеих метрик отношений было слишком широким и заменено этим уточнением.
