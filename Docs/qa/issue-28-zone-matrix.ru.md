## 3. Динамика колонии, main и ветка

`--sim-clock --seeds 12 --animals 10 --minutes 15`, одни и те же сиды на обоих деревьях. Хищника в колонии нет (PR #34: страх идёт от тревожного крика соседа), поэтому раз в 60 с одно бодрствующее животное, выбранное по сиду, получает импульс стресса 0,8; 14 испугов за прогон.

| Метрика (среднее по 12 сидам) | main | ветка |
|---|---|---|
| Смерти, всего | 1 | 0 |
| Рождения | 0 | 0 |
| Средний стресс | 0,442 ± 0,191 | 0,434 ± 0,195 |
| Потребление корма (убыль в мисках) | 0,391 ± 0,012 | 0,395 ± 0,009 |
| Испугов, услышанных другим животным | 59,5 % | 60,7 % |
| Реакция: первое другое животное слышит крик | 1 тик (0,1 с) | 1 тик (0,1 с) |
| Реакция: сосед напуганного прячется или убегает | 1 тик; 167 из 168 испугов | 1 тик; 168 из 168 |
| Каскад тревоги: других кричащих за 20 с | 0,042 | 0,047 |

Траектории в каждом прогоне расходятся, поэтому попарное сравнение по сиду не имеет смысла; сравниваются распределения. Они совпадают. Метрики реакции имеют точность в один тик и на обоих деревьях равны одному тику: прямой крик и там, и там слышен сразу. Снимок меняет только переданный крик (одна зона за тик, §1), а передачи редки (каскад ≈ 0,05).

### 3.1 Два режима стресса (есть и на main)

Прогоны делятся на спокойные и тревожные, на обоих деревьях поровну:

| | main | ветка |
|---|---|---|
| Тревожные (средний стресс > 0,5) | 5 из 12, стресс 0,666, услышано 8 % испугов | 5 из 12, стресс 0,664, услышано 11 % |
| Спокойные | 7 из 12, стресс 0,281, услышано 96 % | 7 из 12, стресс 0,270, услышано 96 % |

Это не следствие правки, об этом — отдельный комментарий. Кратко (сид 3): без испугов колония держится на 0,14–0,21; с ними два испуга к 3-й минуте поднимают всю колонию до 0,66–0,75, и она там остаётся, в основном прячась. Тон `fearful` (стресс > 0,6) знакомого соседа в той же зоне добавляет конфликт (`FEAR_CONTAGION_CONFLICT`, PR #84), и конфликт держит стресс выше 0,6. С этой константой, равной 0, тот же прогон с испугами к 6-й минуте возвращается к 0,24.

## 5. Что не покрыто

- Социальные предложения по-прежнему решаются в ходе инициатора: цель может узнать инициатора в том же тике, поэтому «unknown_nearby» или «nearby» ещё может зависеть от порядка (зоны — нет). Предложения — это issue #25.
- id новорождённых (uuid4) и метки времени социальной памяти хоста (`time.time()`) из issue #14 в правку не входят.
- Стенд идёт 15 минут симуляции; размножение и старость за этим окном.
