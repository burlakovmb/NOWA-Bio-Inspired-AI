## Объём и поведение

Исправляются замечания к checkpoint песочницы в [PR #67](https://github.com/burlakovmb/NOWA-Bio-Inspired-AI/pull/67#issuecomment-6800632152), база `9c95f0282bb289e6c56bb9781492f432958b316a`.

- `_save_intent_memory_extension` сериализует в уникальный временный файл рядом, сбрасывает буферы, синхронизирует и закрывает файл, затем вызывает `os.replace`. Ошибки сериализации и публикации сохраняют прежний файл на границе helper расширения; временный результат по возможности удаляется, ошибка уборки обозначается предупреждением.
- `_load_intent_memory_extension` перехватывает ошибки необязательного чтения, разбора и структуры. Отсутствующий ключ остаётся штатной совместимостью без предупреждения. Некорректное расширение сохраняет прежние привычки, вызывает предупреждение и не срывает успешную загрузку основы. Преобразование происходит до установки ссылок; ошибка их установки откатывает прежние ссылки агента/manager, когда setters допускают восстановление.
- Допускаются корректные пустые коллекции привычек и прежний формат mapping следов. Схема сохранения ядра и параметры обучения не меняются.
- Удалены два дубликата комментария GitHub из `Docs/specs/hippocampal-decay-github-draft-2026-11-09.*`. [Технический отчёт о затухании](hippocampal-decay-persistence-2026-11-09.ru.md) и опубликованные доказательства #16 сохранены.

Реализация: `Demo/Virtual company/src/nowa_sandbox/sandbox_checkpoint.py`. Новое покрытие сбоев: `Demo/Virtual company/tests/test_sandbox_checkpoint_intent_memory.py`. Контракт: [issue #58](../specs/issue-58-sandbox-two-tier-plasticity.ru.md).

## Ограничения

Правка делает атомарной запись расширения, но не превращает всю пару metadata + файл агента в транзакцию и не делает атомарным предшествующее сохранение основы. Повреждённую основу она не восстанавливает. Прежнее требование доверенных локальных pickle остаётся.

Полная квалификация Stage 1a/1b на пяти seed остаётся незавершённой в #58. Правка не квалифицирует, не принимает, не переобучает и не чинит обученного сотрудника. Обходы перепривязки из #68 сохранены до исправления ядра. Необязательные изменения часов, повторения уроков и helper траекторий за пределами этой правки.
