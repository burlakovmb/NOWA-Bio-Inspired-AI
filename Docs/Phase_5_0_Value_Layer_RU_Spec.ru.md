# Phase 5.0 — слой ценности и ошибка TD

English version: [Phase_5_0_Value_Layer_RU_Spec.en.md](Phase_5_0_Value_Layer_RU_Spec.en.md)

**Статус (27 сентября 2026 г.).** Документ ядра. Актуальное научное изложение комплекса на русском и английском языках приведено в [SCIENTIFIC_DESCRIPTION.ru.md](SCIENTIFIC_DESCRIPTION.ru.md). Текст ниже сохраняет формулировки исходной редакции: это нормативный контракт модуля либо лабораторная запись.

## 1. Цель слоя

Ввести полноценный слой ценности состояний (Value Layer), реализующий обучение через ошибку временной разности (TD error):

```text
δ_t = r_t + γ V(s_{t+1}) − V(s_t)
```

Слой должен:
- формировать долгосрочную направленность поведения
- обновлять ценность состояний через ошибку предсказания
- кодировать δ_t через дофамин (но не подменять обучение ценности)
- быть архитектурно изолированным от аффективного фона

---

## 2. Архитектурная позиция

Порядок слоёв:

```text
State → Emotional/Affective → Expectations → Regulation (4.4) → Stability (4.5)
                                                              ↓
                                                       Value Layer (5.0)
                                                              ↓
                                              Action Selection / Planning
```

Value Layer:
- читает снимок состояния
- читает reward
- читает γ
- НЕ изменяет аффективный фон
- НЕ изменяет семантические эмоции
- НЕ изменяет регуляцию

---

## 3. Основные сущности

### 3.1 Функция ценности

```text
|V(s)| ≤ 1 / (1 − γ)   при |r| ≤ 1; дефолт γ = 0.95 → 20
```

(`δ_t` по-прежнему в `[-1, 1]`; см. [issue-18-minor-learning-fixes.ru.md](specs/issue-18-minor-learning-fixes.ru.md).)

Реализация допускает:
- табличную модель (state_hash → value) или
- аппроксимацию (сеть или линейная модель)

Начальная инициализация: V(s) = 0.0

---

### 3.2 Ошибка TD

```text
δ_t = r_t + γ V(s_{t+1}) − V(s_t)
```

Ограничение: δ_t ∈ [-1, 1] (clamp)

---

### 3.3 Обновление

```text
V(s_t) ← V(s_t) + α * δ_t
```

Параметры:
- α (скорость обучения): 0.01–0.1
- γ (коэффициент дисконтирования): 0.90–0.99

---

## 4. Интеграция с дофамином

Дофамин кодирует δ_t, а не reward.

Правило:

```text
dopamine_delta = clamp(δ_t * k, -0.1, 0.1)
```

где k — коэффициент масштабирования.

Важно:
- Дофамин не обновляет аффективный фон напрямую.
- Регуляция (4.4) может сглаживать дофамин через свои ограничения.
- Устойчивость (4.5) мониторит возможный neuromodulator_drift.

---

## 5. Изоляционные ограничения

Value Layer не имеет права:
- изменять эмоциональное состояние напрямую
- изменять фон
- изменять ожидания
- вызывать регуляцию
- изменять консолидацию памяти

Он только:
- обновляет V(s)
- возвращает δ_t
- возвращает текущую оценку V(s)

---

## 6. Интерфейс слоя

```text
update(
    state_snapshot,
    reward: float,
    next_state_snapshot,
    gamma: float,
    alpha: float,
    timestamp: float
) -> {
    "value": float,
    "td_error": float
}
```

---

## 7. Ограничения стабильности

- L2-норма обновлений ценности за такт должна быть ограничена
- δ_t ограничивается диапазоном [-1, 1]
- α динамически может снижаться при неустойчивости
- каскадное обновление более одного раза за такт не допускается

---

## 8. Расширения (будущие фазы)

Возможны:
- следы пригодности (TD(λ))
- многошаговый бутстрэп
- раздельные ценность цели и ценность состояния
- связь с мотивационными системами

---

## 9. Ожидаемый эффект

После внедрения:
- агент начинает корректировать ожидания системно
- появляется долговременный вектор предпочтений
- reward превращается в неожиданность
- поведение становится траекторным, а не реактивным

---

Phase 5.0 считается завершённой, когда:
- ошибка TD корректно вычисляется
- V(s) стабильно обучается
- нет дрейфа нейромодуляторов
- устойчивость (4.5) остаётся в допустимых пределах
