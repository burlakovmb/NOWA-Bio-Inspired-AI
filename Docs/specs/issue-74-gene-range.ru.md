# Issue #74 — диапазон гена `af_baseline_adapt_rate`

English: [issue-74-gene-range.en.md](issue-74-gene-range.en.md)

PR #81, ветка `team/issue-74-gene-range`. Код: `src/genome.py`, `src/storage.py`.

---

## Проблема

Границы гена были `[0, 0.01]` за симулированную секунду. Равномерная случайная выборка давала **медиану τ ≈ 200 с** к «прожитой» оси — слишком быстро для аллостатического дрейфа baseline, который должен идти **часами** (модель issue #54).

## Биологическое обоснование

Хронический стресс и аллостатическая нагрузка в аффективном ядре должны сдвигать `baseline` за часы (дефолт τ ≈ 6 ч), а не за минуты. Эволюция и мутация должны исследовать только правдоподобные скорости адаптации (порядка 1,5–24 ч для основной скорости).

## Новое поведение

| Элемент | Значение |
| --- | --- |
| min / max гена | `1/86400` … `1/5400` (τ ≈ 24 ч … 1,5 ч) |
| Дефолт | `1/21600` без изменений (τ ≈ 6 ч) |
| Сигма | `0.5/21600` без изменений |
| После random / mutate / crossover | Зажим в границы гена; τ в 1,5–24 ч |

Прямое создание `AffectiveSpace` (тесты) по-прежнему жмёт `baseline_adapt_rate` в `[0, 0.2]` в `__post_init__` — без изменений.

## Старые сохранения и геномы

Значения вне диапазона гена (напр. rate `0.002` до #54 в `.nowa` или в словаре генома) грузятся через `GenomeVector.from_dict` и `AgentStorage.load_agent`: **одно `RuntimeWarning`**, значение в `[min, max]` (напр. `0.002` → `1/5400`). In-range и отсутствующий ключ (дефолт реестра) — без предупреждения. Это заменяет политику issue #54 «читать 0.002 как есть (τ ≈ 8 мин)» после #74.
