## Согласование с реализацией (2026-02-19)

Этот раздел фиксирует поведение, реализованное в `src/affective_space.py`,
и пути интеграции в `src/agent.py` и `src/storage.py`.

### 1. Канонический источник истины

- Источник истины во время выполнения: `AffectiveSpace.axes`.
- `affect_state` — проекция совместимости из канонического состояния.
- Выбор базальных ганглиев потребляет каноническое `affective_space`.

### 2. Унаследованная аддитивная динамика необязательна

- Унаследованный аддитивный член (`compat_delta`) управляется `legacy_compat_weight`.
- Значение по умолчанию равно `0.0`, поэтому унаследованная аддитивная динамика по умолчанию отключена.
- Это предотвращает случайный двойной вклад инерции и шума.

### 3. Поведение динамического потолка нормы

- Потолок нормы во время выполнения динамичен (`dynamic_norm_cap`) и имеет параметры:
  - `norm_cap_base`
  - `norm_cap_max`
  - `norm_cap_adapt_rate`
  - `norm_cap_release_rate`
  - `norm_cap_global_release_rate`
- Рост замедляется вблизи `norm_cap_max` за счёт ослабления запаса до потолка.
- Медленное глобальное отпускание предотвращает долгое залипание у максимума потолка.

### 4. Динамический базовый уровень

- Baseline адаптируется в **симулированных секундах** через `baseline_adapt_rate` (дефолт ≈ `1/(6×3600)` в секунду) к «прожитой» оси; к фиксированному `baseline_setpoint` (`b0`) — с четвертью этой скорости.
- Дрейф ограничен и обрезается по каждой оси.
- Полные правила: [specs/issue-54-affect-simulated-time.ru.md](specs/issue-54-affect-simulated-time.ru.md).

### 5. Покрытие сохранения и загрузки

`AffectiveSpace.to_dict()/from_dict()` и `AgentStorage.load_agent(...)` включают:

- `baseline_adapt_rate`
- `baseline_setpoint`

- `axis_decay` (с псевдонимом `affective_decay`)

## 1. Архитектурный принцип

### 1.1 Единственный источник эмоционального состояния

Существует только один объект текущего эмоционального состояния:

```
A(t) ∈ ℝ^N
```

Это:

- непрерывное
- динамическое
- нормированное
- читается слоем решений

> Никаких параллельных контейнеров состояния не допускается.

---

## 2. Онтология эмоции

Эмоция определяется как процесс из трёх фаз:

1. Возникновение импульса
2. Интеграция в состояние
3. Затухание

---

## 3. Структуры данных

### 3.1 Аффективное состояние

```
A(t): float[N]
range per axis: [-1, 1]
```

**Размерность N:** 8–16

**Минимальный базис:**

| Ось        | Описание              |
|------------|-----------------------|
| Valence    | валентность           |
| Arousal    | возбуждение           |
| Dominance  | доминирование         |
| Stress     | стресс                |
| Trust      | доверие               |
| Curiosity  | любопытство           |
| Stability  | стабильность          |
| Attachment | привязанность         |

### 3.2 Эмоциональный импульс

Временный оператор изменения состояния.

```
EmotionImpulse {
    vector:    ℝ^N
    intensity: [0, 1]
    source:    { external, memory, internal }
}
```

> Импульс **не хранится** как состояние.

### 3.3 Эмоциональный след (память)

```
EmotionalTrace {
    snapshot_vector: ℝ^N
    intensity:       [0, 1]
    timestamp
    decay_rate
}
```

> След не участвует напрямую в `A(t)`. Он **может генерировать новый импульс**.

---

## 4. Обновление состояния

### 4.1 Основное уравнение

> **Реализация (issue #54):** живой интегратор использует удержание за секунду в степени `time_elapsed`, движущийся baseline с `baseline_setpoint` и импульсы в конце интервала. См. [specs/issue-54-affect-simulated-time.ru.md](specs/issue-54-affect-simulated-time.ru.md). Дискретная формула ниже — частный случай `dt=1` исходного контракта.

```
A_axis(t+1) = Baseline_axis
            + axis_decay[axis] * (A_axis(t) - Baseline_axis)
            + Σ ExternalImpulses_axis
            + Σ RecallImpulses_axis
            + Σ InternalImpulses_axis
            - λ * (A_axis(t) - Baseline_axis)
```

**Параметры:**

| Параметр | Диапазон      | Роль |
|----------|---------------|------|
| `axis_decay[axis]` | [0.0, 0.999] | Пер-осевая инерция |
| `α` (`alpha`) | [0.7, 0.95] | Унаследованный запасной вариант для осей без явного `axis_decay` |
| `λ` (`lambda_reg`) | [0.01, 0.1] | Регулятор возврата |
| `Baseline` | базовый вектор личности | Базовый вектор личности |

Дефолтные значения `axis_decay`:

- `valence=0.92`
- `arousal=0.80`
- `dominance=0.97`
- `stress=0.75`
- `curiosity=0.78`
- `trust=0.95`

### 4.2 Ограничения

```
||A(t)|| ≤ 1.5
Ни одна ось не выходит за [-1, 1]
RecallImpulse ≤ 0.3 * mean(ExternalImpulse)
ΣRecall ≤ 40% от суммарного воздействия
```

## 5. Замкнутый контур влияния

### 5.1 Слой решений

Слой решений читает **только** `A(t)` и формирует:

```
DecisionBias = W * A(t)
```

**W** — матрица влияния эмоций на:

- риск
- скорость ответа
- выбор слов
- степень эмпатии
- приоритет целей

### 5.2 Поведение влияет на эмоции

После действия:

1. создаётся событие
2. событие генерирует новый импульс
3. цикл продолжается

> Контур замкнут.

---

## 6. Память и повторная активация

При вспоминании:

```
Recall(E_i) → generate EmotionalImpulse E'_i
где: E'_i = k * snapshot_vector
     k ∈ [0.1, 0.4]
```

> Это **не перезапись** состояния, а **новый импульс**.

---

## 7. Инварианты устойчивости

- Нет второго эмоционального контейнера
- Слой решений не читает импульсы
- Импульсы не сохраняются как состояние
- Память не модифицирует `A(t)` напрямую
- При отсутствии стимулов `A(t) → Baseline`

## 8. Тест-кейсы

### Тест 1 — Нейтральная среда
**Условие:** нет импульсов
**Ожидается:** `A(t)` экспоненциально сходится к `Baseline`

### Тест 2 — Сильный позитивный стимул
**Условие:** один `ExternalImpulse` высокой интенсивности
**Ожидается:**
- валентность растёт
- возбуждение растёт
- постепенное затухание

### Тест 3 — Вспоминание травматической памяти
**Условие:** создаётся `RecallImpulse`
**Ожидается:**
- смещение `A(t)`
- не превышает 30% среднего внешнего импульса
- нет неуправляемого роста

### Тест 4 — Конфликт прошлого и настоящего
**Условие:** положительный стимул и негативное вспоминание
**Ожидается:**
- итоговое состояние — векторная сумма
- текущее доминирует

### Тест 5 — Длительное давление
**Условие:** много малых импульсов `stress`
**Ожидается:**
- медленный дрейф оси `Stress`
- после прекращения — возврат к `Baseline`

## 9. Отсутствие конфликта с фазой 4

**Фаза 4** переопределяется как:

- генератор `EmotionalImpulses`
- генератор `EmotionalTraces`

**Аффективное ядро:**

- интегратор
- регулятор
- источник состояния для решений

> Нет дублирования. Нет двух состояний. Нет двух источников истины.

---

## 10. Поведенческое следствие

Теперь эмоции:

- влияют на принятие решений
- влияют на стиль ответа
- влияют на стратегию
- могут усиливаться через повтор
- могут затухать
- могут создавать инерцию

**И главное:**

> Агент существует между событиями.
