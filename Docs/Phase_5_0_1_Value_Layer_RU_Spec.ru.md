# Фаза 5.0.1 — Слой ценности и ошибка TD (инженерная версия)

English version: [Phase_5_0_1_Value_Layer_RU_Spec.en.md](Phase_5_0_1_Value_Layer_RU_Spec.en.md)

**Статус (27 сентября 2026 г.).** Документ ядра. Актуальное научное изложение комплекса на русском и английском языках приведено в [SCIENTIFIC_DESCRIPTION.ru.md](SCIENTIFIC_DESCRIPTION.ru.md). Текст ниже сохраняет формулировки исходной редакции: это нормативный контракт модуля либо лабораторная запись.


## 1. Цель

Реализовать полноценный слой оценки состояний V(s) с обучением через ошибку
TD:

δ_t = r_t + γ V(s\_{t+1}) − V(s_t)

Добавлены уточнения:
- формализация кодирования состояния
- политика хранения ценности
- чёткая интеграция с дофамином
- ограничения на подкрепление
- рекомендованные гиперпараметры
- набор тест-кейсов

------------------------------------------------------------------------

## 2. Кодирование состояния

### 2.1 Требования

`StateEncoder` должен:

- быть детерминированным
- использовать только `state_snapshot`
- не использовать аффективный фон
- не использовать уровни нейромодуляторов
- не использовать состояние регуляции

### 2.2 Формат

Рекомендуется:

`state_key = hash(normalized_state_representation)`

где `normalized_state_representation`:
- словарь с фиксированным набором признаков
- сортировка ключей обязательна
- значения округляются до фиксированной точности (например 3 знака)

### 2.3 Ограничения

- размерность состояния должна быть ограничена
- запрещено включать шумовые или высокочастотные параметры

### 2.4 Семантическая векторизация текстовых признаков (реализовано)

Для текстовых полей в `state_features/state_vector` используется
детерминированное семантическое хеширование:

1. `tokenize(text)`:
   - приведение к нижнему регистру (`casefold`)
   - разбиение по не-словесным символам и `_`
   - пример: `eat_food -> ["eat", "food"]`
2. `word_vec(token)`:
   - стабильный хеш SHA-256 по `(token, index)`
   - проекция в диапазон `[-1, 1]`
   - нормализация в единичный вектор
3. `semantic_vector(text)`:
   - усреднение `mean(word_vec(t))` по токенам
   - финальная нормализация
4. Сходство:
   - косинусное сходство между векторами состояний

Свойства:
- детерминированность между запусками
- низкая стоимость без тяжёлых вложений
- устойчивость к вариантам разделителей (`eat_food` и `eat food`)

------------------------------------------------------------------------

## 3. Хранение ценности

### 3.1 Модель

V хранится как:

`Dict[state_key, float]`

### 3.2 Ограничение размера

- `max_states` = 50_000 (рекомендуется)
- при превышении — вытеснение по LRU

### 3.3 Инициализация

V(s) по умолчанию = 0.0

------------------------------------------------------------------------

## 4. Ошибка TD

δ_t = r_t + γ V(s\_{t+1}) − V(s_t)

### 4.1 Ограничения

- δ_t ограничивается интервалом [-1, 1]
- |V(s)| ≤ 1 / (1 − γ) при |r| ≤ 1; дефолт γ = 0.95 → 20 (см. [issue-18-minor-learning-fixes.ru.md](specs/issue-18-minor-learning-fixes.ru.md))
- одно обновление за такт

### 4.2 Рекомендованные параметры

`alpha` = 0.03, `gamma` = 0.95

------------------------------------------------------------------------

## 5. Интеграция с дофамином

### 5.1 Правило

`dopamine_delta = clamp(δ_t * k, -0.1, 0.1)`

где k = 0.5 (рекомендуется)

### 5.2 Критическое ограничение

- обновление дофамина является аддитивным
- проходит через стандартное ограничение слоя нейромодуляторов
- не влияет напрямую на аффективный фон
- не влияет на подкрепление

Разрыв цикла обязателен:

ценность → дофамин → (ограничения регуляции) → нет прямой обратной связи в подкрепление

------------------------------------------------------------------------

## 6. Ограничение подкрепления

Подкрепление должно:

- вычисляться до аффективной регуляции
- не зависеть от текущего дофамина
- не зависеть от слоя ценности

Подкрепление может быть:
- внешним
- основанным на задаче
- основанным на среде

------------------------------------------------------------------------

## 7. Интерфейс

```text
update( state_snapshot, reward: float, next_state_snapshot, gamma: float
= 0.95, alpha: float = 0.03, timestamp: float ) -> { "value": float,
"td_error": float, "state_key": str }
```

------------------------------------------------------------------------

## 8. Ожидаемая динамика

После 1000+ шагов:

- появляется распределение V(s)
- возникает асимметрия предпочтений
- появляется устойчивый сдвиг в сторону выгодных состояний

------------------------------------------------------------------------

# 9. Тест-кейсы

## 9.1 Положительный сюрприз

Сценарий:
- V(s_t) = 0.2
- подкрепление = 0.8
- V(s_{t+1}) = 0.3

Ожидается: δ > 0, `dopamine_delta` > 0, V(s_t) увеличивается

------------------------------------------------------------------------

## 9.2 Отрицательный сюрприз

Сценарий:
- V(s_t) = 0.6
- подкрепление = 0.1
- V(s_{t+1}) = 0.2

Ожидается: δ < 0, `dopamine_delta` < 0, V(s_t) уменьшается

------------------------------------------------------------------------

## 9.3 Нулевой сюрприз

Сценарий:
- подкрепление соответствует ожиданию

Ожидается: δ ≈ 0, `dopamine_delta` ≈ 0, V(s_t) стабильно

------------------------------------------------------------------------

## 9.4 Нагрузочный тест устойчивости

- 10_000 обновлений
- проверить:
  - V остаётся в |V| ≤ 1 / (1 − γ) для активного γ и |r| ≤ 1
  - нет `neuromodulator_drift`
  - индекс устойчивости > 0.6

------------------------------------------------------------------------

## 9.5 Тест нагрузки памяти

- превышение `max_states`
- проверить корректность вытеснения LRU

------------------------------------------------------------------------

## 9.6 Тест изоляции дофамина

- проверить, что изменение δ не изменяет подкрепление
- проверить отсутствие циклического усиления

------------------------------------------------------------------------

Фаза 5.0.1 считается успешной, если:

- ценность сходится
- δ распределён симметрично вокруг 0
- устойчивость (4.5) остаётся устойчивой
- нет неуправляемого усиления
