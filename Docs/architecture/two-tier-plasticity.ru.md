# Двухуровневая пластичность (ядро NOWA)

English: [two-tier-plasticity.en.md](two-tier-plasticity.en.md)

Нормативная спецификация: [Docs/specs/issue-13-two-tier-plasticity.ru.md](../specs/issue-13-two-tier-plasticity.ru.md).  
Порядок сна: [Docs/SLEEP.ru.md](../../Docs/SLEEP.ru.md).  
API: [Docs/API.ru.md](../../Docs/API.ru.md).

Когнитивное ядро в `src/` — **универсальный движок**. Хост задаёт время, исходы и момент сна; он не описан здесь. Примеры хостов в `Demo/` — только в разделе [Демо-хосты](#демо-хосты).

## Уровни

| Уровень | Содержимое | Когда пишется |
|---------|------------|----------------|
| **Стабильный** | Q/V и статистика ожиданий `ValueLayer`; стабильные счётчики визитов; силы следов привычек (&gt; 0); `go_weight` / `nogo_weight` / `habit_strength` BG; паттерны коры; временные цепочки; веса стратегий и обучаемые поля селектора; медленная аффективная статистика; базовые линии нейромодуляторов (в отпечатке) | Только внутри `Agent.sleep()` под `learning_allowed()` |
| **Лабильный** | Ограниченные добавки `L_Q`, `L_go`, `L_nogo`; вклады эпизодов; дневные счётчики визитов (без затухания) | Бодрствование, при фиксации исхода |
| **Состояние** | Уровни нейромодуляторов, быстрый аффект, бодрость, рабочий контекст, эпизоды гиппокампа, часы хоста | Бодрствование и сон (не в `stable_fingerprint`) |

**Инвариант W:** между двумя вызовами `Agent.sleep()` значение `stable_fingerprint(agent)` не меняется при любых дневных API.

**Инвариант S:** стабильные параметры меняются только в консолидации из `Agent.sleep()`. Каждый эпизод с известным исходом консолидируется **не более одного раза** за ночь (смена оценки *после* консолидации — **новое** наблюдение в следующем сне, без отката).

**Выбор:** эффективные значения = стабильное + лабильное; сила привычки в затворе — только **стабильный** след.

## Дневное обучение (`LabileLayer`)

Код: `src/labile_layer.py`, вызовы из `step`, `commit_executed_transition`, `apply_feedback_to_last_experience`.

При известном исходе:

- δ считается по **эффективному** Q.
- `ΔL_Q = clamp(η_L · g_DA · δ, ±a_step)`, суммарный `L_Q` в `±A_Q`. По умолчанию `η_L = 0.1 × alpha_reference` (часто `alpha_default` = 0.03 → `η_L ≈ 0.003`), `a_step = 0.05`, `A_Q = 0.2`.
- Канал: при `r > 0` — `ΔL_go = η_Lc·r`, `ΔL_nogo = −½η_Lc·r`; при `r < 0` — с множителем ½ на Go. По умолчанию `η_Lc = 0.02`, `A_c = 0.1`.
- **`g_DA` = 1** (без масштабирования от уровня дофамина).
- Привычки: `note_selection` может создать след **силы 0**; исход днём силу не меняет.
- **Награды:** `NaN` — неизвестно; `±inf` → `±1` в `step` / `commit_executed_transition`.

**Затухание:** `L ← L · exp(−Δt/τ_L)`. Время хоста: `dt` в шагах или `advance_time`. `τ_L = tau_labile_ratio × expected_wake_interval_s` (ratio `1.0`). Без интервала — предупреждение и **3600 с**. `|L| < 1e-6` удаляется.

**Feedback:** та же оценка — no-op; новая — снять вклад эпизода и записать один раз.

**Визиты:** лабильные счётчики не затухают; во сне перенос в `_action_visit_counts` и сброс.

## Guard обучения

Код: `src/learning_guard.py`.

| Контекст | Назначение |
|----------|------------|
| `learning_allowed()` | `Agent.sleep()` / `deep_sleep()` |
| `initializing()` | Создание, загрузка, посев; `register_action_channel` входит **сам** |
| `NOWA_STRICT_LEARNING=1` | Тесты: `WakingLearningError` при дневной записи в стабильный слой |
| Продакшен | Один лог на имя писателя и **пропуск** записи |

Guard для обучения открывает только сон. `_apply_replay_td_bg` guard не открывает.

## `stable_fingerprint` и `labile_snapshot`

SHA-256 канонического JSON категории A: value layer, визиты, силы привычек (&gt; 0), каналы BG, кора, temporal chains, стратегии (включая `PlasticityConfig`), `slow_affect`.

**Вне** отпечатка: лабильный слой, эпизоды, быстрый аффект, живые уровни нейромодуляторов, часы хоста.

`labile_snapshot(agent)` — лабильный слой на `_host_clock_s`.

## Интеграция хоста

1. `PlasticityConfig(expected_wake_interval_s=...)` при создании агента.
2. На каждом тике: `dt` в `step` / `commit_executed_transition` или `advance_time`.
3. `agent.sleep(...)` по расписанию хоста.
4. `register_action_channel` для новых действий.
5. После загрузки — посев стабильного слоя в `with initializing():`.
6. В тестах: `NOWA_STRICT_LEARNING=1`.

`PlasticityConfig`, лабильный слой и часы сохраняются в save/load.

На диске это поля документа JSON `nowa-agent-state` (схема `1`, расширение `.nowa`), не pickle. См. [issue-16-31-safe-agent-state.ru.md](../specs/issue-16-31-safe-agent-state.ru.md). Старые `.pkl` отвергаются; после обновления чекпоинты пересоздают.
