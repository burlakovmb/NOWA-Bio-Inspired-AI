# Колония шиншилл: научное описание экспериментальной установки

English version: [COLONY_SPEC.en.md](COLONY_SPEC.en.md)

### 1. Предмет

Установка моделирует популяцию, в которой каждая особь есть автономный агент NOWA. Среда есть клетка с зонами и нормированными ресурсами. Вопрос прогона — возникновение демографической и социальной динамики при отсутствии центрального диспетчера политики: связи, смена поколений, распределение ресурса, риск вымирания.

### Эволюция в действии

Колония с зерном генератора 11, выведенная через этот бегунок и снятая существующими оверлеями. Имена — идентификаторы колонии. Полные галереи на английском и русском — в разделе README [Эволюция в действии](../../../README.md#evolyutsiya-v-deystvii).

### 2. Состав

| Модуль | Функция |
|---|---|
| `src/colony_agent.py` | Когнитивный шаг, гомеостаз, социальное поведение, размножение, смертность |
| `src/simulation_runner.py` | Такт популяции, рождения и смерти, пополнение ресурсов |
| `src/colony_swarm_bridge.py` | Синхронизация с роевой средой: положение, сигналы, экология, проверка пар |
| `src/colony_gui/` | Слой отображения; читает снимки и не изменяет решение |
| `src/colony_storage.py` | Сохранение и загрузка бегунка и состояния особей |
| `src/colony_population_observer.py` | Пассивные снимки, тренды, риск вымирания, сплочённость |

Исполняемый код установки расположен в `src/`.

### 3. Инварианты

1. Графический интерфейс и наблюдатель популяции не изменяют когнитивное решение.
2. Каноническое отображаемое имя особи имеет вид `G<поколение>A<индекс>S<пол>`. Регулярное выражение: `^G[0-9]+A[0-9]+S[MFU]$`. Пример: `G0A1SM`, `G2A5SF`.
3. Отдельный жёсткий предел жизни колонии в секундах не задаётся.
4. Исключительные ресурсы остаются исключительными на всём пути: блокировка в `SharedResources` и визуальная исключительность колеса и купалки в интерфейсе.
5. События смерти дописываются в JSONL. Путь по умолчанию: `Demo/Colony chinchillas/logs/deaths.jsonl`.
6. Счётчики жизненного цикла бегунка: `births_this_step`, `deaths_this_step`, `total_births`, `total_deaths`.

Гомеостатический ограничитель особи может отменить когнитивно выбранное действие при критическом голоде, жажде или усталости. Ограничение принадлежит телу.

### 4. Наблюдаемые величины и параметры цикла

Половая зрелость — 900 единиц модельного времени; беременность — 300; длина эстрального цикла — 600; эструс — 180; пополнение корма, сена и воды до 1,0 — каждые 600 единиц; старость ограничена на особь: `COLONY_MAX_LIFESPAN_AGE_S` (13 500 с, 15 × зрелость) × `lt_max_lifespan_factor` (реестр 0.5..2.0; по умолчанию 13 500 с). `COLONY_MAX_LIFESPAN_STEPS` (20 000) остаётся только для снимков и нормализации индекса здоровья. Принятие спаривания требует эструса самки. Смерть от старости идёт по биологическому возрасту в сим-секундах, а не по числу решений; истощение и депривация сна остаются физиологическими причинами. Журнал смерти хранит причину, модельное время, энергию, бодрствование, стресс и кортизол.

### 5. Воспроизведение

Графический режим:

```bash
cd "Demo/Colony chinchillas/src"
python gui.py --agents 4
```

Прогон без интерфейса:

```bash
cd "Demo/Colony chinchillas/src"
python gui.py --headless --agents 4 --duration 5
```

Модульный запуск: `python -m colony_gui --agents 4` из каталога `src`.

Проверка:

```bash
cd "Demo/Colony chinchillas"
python -m pytest -q tests
```

При нулевой численности в интерфейсе причина устанавливается по последним записям `deaths.jsonl`.
